# 📧 ইমেইল সিমুলেটর — একটি পাইথন OOP প্রজেক্ট

একটি ছোট কিন্তু পূর্ণাঙ্গ, **কনসোল-ভিত্তিক ইমেইল সিমুলেশন**, যা সম্পূর্ণভাবে পাইথনের
অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং (OOP) ফিচার দিয়ে তৈরি। কোনো এক্সটার্নাল লাইব্রেরি নেই, নেটওয়ার্কিং
নেই — শুধু পরিষ্কার ক্লাস, কম্পোজিশন আর ম্যাজিক মেথড মিলে একটি আসল ইনবক্সের মূল জীবনচক্র অনুকরণ
করছে: **ইউজার তৈরি → ইমেইল পাঠানো → ইনবক্সের তালিকা → ইমেইল পড়া → ইমেইল মুছে ফেলা।**

---

## ১. 🎯 প্রজেক্টের উদ্দেশ্য ও লক্ষ্য

### উদ্দেশ্য
একটি সরলীকৃত ইমেইল সিস্টেম ভেতরে কীভাবে কাজ করে তা OOP ব্যবহার করে মডেল করা — যাতে বাস্তব
জগতের প্রতিটি ধারণা (একটি ইমেইল, একজন ইউজার, একটি ইনবক্স) নিজস্ব ক্লাস হয়ে ওঠে, যার নিজস্ব
ডেটা ও দায়িত্ব থাকে। এটি একটি শিক্ষামূলক/প্রদর্শনী প্রজেক্ট, যা দেখায় কীভাবে অবজেক্টগুলো একসাথে
কাজ করে একটি পূর্ণ ফিচার তৈরি করে।

### লক্ষ্যসমূহ
- ✅ **Encapsulation** দেখানো — প্রতিটি ক্লাস নিজের ডেটা লুকিয়ে রাখে ও নিজেই তার মালিক।
- ✅ **Composition** দেখানো — অন্য অবজেক্ট দিয়ে অবজেক্ট গড়া (`User`-এর একটি `Inbox` *আছে*,
  `Email`-এর একটি `sender`/`receiver` *আছে*)।
- ✅ **ম্যাজিক/ডান্ডার মেথড** (`__init__`, `__str__`) দেখানো, যা অবজেক্ট তৈরি ও স্ট্রিং
  উপস্থাপনা নিয়ন্ত্রণ করে।
- ✅ টাইমস্ট্যাম্পের জন্য **`datetime` মডিউল**-এর বাস্তব ব্যবহার দেখানো।
- ✅ **ডিফেন্সিভ প্রোগ্রামিং** দেখানো — খালি ইনবক্স ও ইনডেক্স-সীমা ভ্যালিডেশন।
- ✅ একটি পরিষ্কার, পঠনযোগ্য **ড্রাইভার (`main`)** দেওয়া, যা একটি পূর্ণ ইউজার-যাত্রা সিমুলেট করে।

### প্রোগ্রামটি যা যা করতে পারে
| কাজ | মেথড চেইন |
|---|---|
| ইউজার তৈরি | `User(name)` |
| ইমেইল পাঠানো | `user.send_email(receiver, subject, body)` |
| ইনবক্সের তালিকা | `user.check_inbox()` |
| একটি ইমেইল পড়া | `user.read_email(index)` |
| একটি ইমেইল মুছা | `user.delete_email(index)` |

## ২. 🧰 ব্যবহৃত প্রযুক্তি ও OOP ধারণা

| ধারণা | কোথায় ব্যবহৃত | কেন ব্যবহার করা হয়েছে |
|---|---|---|
| **ক্লাস ও অবজেক্ট** | `Email`, `User`, `Inbox` | বাস্তব জগতের প্রতিটি "জিনিস" একটি পুনঃব্যবহারযোগ্য ব্লুপ্রিন্ট হয়ে ওঠে। অবজেক্ট সম্পর্কিত ডেটা + আচরণ একত্রে রাখে, ফলে কোড সুসংগঠিত ও পঠনযোগ্য থাকে। |
| **Encapsulation** | `self.emails`, `self.read`-এর মতো অ্যাট্রিবিউট | প্রতিটি ক্লাস নিজের state-এর মালিক ও রক্ষক; বাইরের কোড ভেতরের জিনিস না নিয়ে মেথডের মাধ্যমে যোগাযোগ করে। |
| **Composition** | `User.__init__`-এ `self.inbox = Inbox()` তৈরি; `Email`-এ `sender`/`receiver` User অবজেক্ট সংরক্ষণ | "has-a" সম্পর্ক বাস্তবসম্মতভাবে মডেল করে। *অবজেক্ট* (স্ট্রিং নয়) সংরক্ষণ করায় পরে `sender.name` / `receiver.inbox`-এ পৌঁছানো যায় — অনেক বেশি নমনীয়। |
| **কনস্ট্রাক্টর (`__init__`)** | তিনটি ক্লাসেই | প্রতিটি নতুন অবজেক্টের শুরুর অবস্থা স্বয়ংক্রিয়ভাবে তৈরি করে (যেমন জন্মের মুহূর্তেই প্রতি ইউজার নিজস্ব খালি ইনবক্স পায়)। |
| **ম্যাজিক মেথড `__str__`** | `Email.__str__` | তালিকায় একটি ইমেইল কীভাবে ছাপা হবে তা নিয়ন্ত্রণ করে — কুৎসিত `<...object at 0x...>`-কে পরিষ্কার এক-লাইনের সারাংশে রূপান্তর করে। `print()`/f-string-এর মাধ্যমে পাইথন এটি স্বয়ংক্রিয়ভাবে কল করে। |
| **`datetime` মডিউল** | `Email.__init__`, `display_full_email`, `__str__` | তৈরির মুহূর্তটি আসল `datetime` অবজেক্ট হিসেবে ধরে রাখে, ফলে ইচ্ছেমতো `.strftime('%Y-%m-%d %H:%M')` দিয়ে সাজানো যায় (যেমন `2026-07-28 23:13`)। |
| **ডেলিগেশন / Separation of Concerns** | `User`-এর মেথডগুলো `Inbox`-এর কাছে পাঠায় | `User` সমন্বয় করে; `Inbox` লিস্ট লজিক ও ভ্যালিডেশনের মালিক। ভবিষ্যতে সংরক্ষণ বদলালে শুধু `Inbox` ছুঁতে হয়। |
| **ভ্যালিডেশন / গার্ড ক্লজ** | `list_emails`, `read_email`, `delete_email` | খালি ইনবক্স বা সীমার বাইরে ইনডেক্সে early `return` ক্র্যাশ (`IndexError`) ঠেকায় ও বন্ধুত্বপূর্ণ বার্তা দেয়। |
| **এন্ট্রি-পয়েন্ট গার্ড** | `if __name__ == '__main__':` | শুধু সরাসরি চালানো হলেই `main()` চলে, ফলে ফাইলটি পার্শ্ব-প্রতিক্রিয়া ছাড়াই মডিউল হিসেবে ইম্পোর্ট করা যায়। |

### বিল্ট-ইন টুলসমূহ
- **`datetime.datetime.now()`** — বর্তমান স্থানীয় তারিখ + সময়।
- **`datetime.strftime()`** — একটি datetime-কে কাস্টম স্ট্রিং-এ সাজানো।
- **`enumerate(iterable, start=1)`** — মানুষের সুবিধাজনক ১-ভিত্তিক কাউন্টারসহ লুপ।
- **`del list[i]** — অবস্থান ধরে উপাদান মুছে ফেলা (পরের আইটেমগুলো নিচে নেমে আসে)।
- **f-string** — পরিষ্কার, ইনলাইন স্ট্রিং ফরম্যাটিং।

## ৩. 🏗️ ক্লাস আর্কিটেকচার

```
┌──────────────────────────────────────────────────────────────┐
│                          User                                 │
│  অ্যাট্রিবিউট: name, inbox (একটি Inbox অবজেক্ট)                  │
│  মেথড: send_email(), check_inbox(), read_email(),            │
│        delete_email()                                        │
│  ভূমিকা: "কর্মী" (actor) — ইনবক্সের মালিক ও কাজ সম্পাদন করে      │
└───────────────┬───────────────────────────┬───────────────────┘
      মালিকানা  │                           │ তৈরি/পাঠানো
                ▼                           ▼
┌───────────────────────────────┐   ┌──────────────────────────────────┐
│            Inbox              │   │              Email                │
│ অ্যাট্রিবিউট: emails (লিস্ট)     │   │ অ্যাট্রিবিউট: sender (User),        │
│ মেথড: receive_email(),        │   │   receiver (User), subject, body, │
│   list_emails(), read_email(),│   │   timestamp (datetime), read(bool)│
│   delete_email()              │   │ মেথড: mark_as_read(),             │
│ ভূমিকা: Email অবজেক্টের লিস্ট   │   │   display_full_email(), __str__() │
│   সংরক্ষণ ও ভ্যালিডেশন করে        │   │ ভূমিকা: একটি একক বার্তা ও তার তথ্য   │
└───────────────────────────────┘   └──────────────────────────────────┘
```

### 🔹 `Email` — বার্তা
একটি ইমেইল ও তার সম্পর্কিত সবকিছুকে প্রতিনিধিত্ব করে।
- **অ্যাট্রিবিউট**
  - `sender` — যে `User` অবজেক্ট পাঠিয়েছে (অবজেক্ট, স্ট্রিং নয় → `sender.name` সম্ভব করে)।
  - `receiver` — যে `User` অবজেক্ট পাচ্ছে।
  - `subject`, `body` — টেক্সট কন্টেন্ট।
  - `timestamp` — তৈরির সময় একবার সেট করা একটি `datetime` অবজেক্ট (`datetime.datetime.now()` দিয়ে)।
  - `read` — বুলিয়ান ফ্ল্যাগ, ডিফল্ট `False` (অপঠিত)।
- **মেথড**
  - `mark_as_read()` — `read`-কে `True` করে।
  - `display_full_email()` — পূর্ণ ইমেইল ছাপায় (From/To/Subject/Received/Body) **এবং**
    পঠিত চিহ্নিত করে, কারণ খোলা মানেই দেখা হয়েছে। সময়ের জন্য `strftime` ব্যবহার করে।
  - `__str__()` — `[Read]`/`[Unread]` ব্যাজসহ সংক্ষিপ্ত এক-লাইনের সারাংশ ফেরত দেয়;
    তালিকায় ইমেইল ছাপার সময় স্বয়ংক্রিয়ভাবে কল হয়।

### 🔹 `User` — অ্যাকাউন্ট / কর্মী
একজন ব্যক্তি ও তার সক্ষমতাগুলোকে প্রতিনিধিত্ব করে।
- **অ্যাট্রিবিউট**
  - `name` — প্রদর্শনের নাম (From/To লাইন ও হেডারে ব্যবহৃত)।
  - `inbox` — `__init__`-এ তৈরি একটি **নতুন `Inbox()`** (composition: User-এর একটি Inbox *আছে*)।
- **মেথড**
  - `send_email(receiver, subject, body)` — একটি `Email(sender=self, ...)` গড়ে
    `receiver.inbox.receive_email(email)`-এর মাধ্যমে ডেলিভার করে, তারপর নিশ্চিতকরণ ছাপায়।
  - `check_inbox()` — একটি হেডার ছাপায় এবং `inbox.list_emails()`-এর কাছে দায়িত্ব দেয়।
  - `read_email(index)` / `delete_email(index)` — ইনবক্সের কাছে পাঠায় (যে লিস্ট ও
    ভ্যালিডেশনের মালিক)। এতে `User` হালকা থাকে এবং `Inbox` নিজের ডেটার দায়িত্বে থাকে।

### 🔹 `Inbox` — সংরক্ষণ ও ভ্যালিডেশন স্তর
প্রাপ্ত ইমেইলের সংগ্রহের মালিক।
- **অ্যাট্রিবিউট**
  - `emails` — `Email` অবজেক্টের একটি লিস্ট (ক্রম = আগমন-ক্রম)।
- **মেথড**
  - `receive_email(email)` — লিস্টের শেষে `append` করে।
  - `list_emails()` — খালি হলে "Your inbox is empty." ছাপিয়ে early return করে; না হলে
    `enumerate(..., start=1)` দিয়ে লুপ করে `f'{i}. {email}'` ছাপায় (যা `__str__` ট্রিগার করে)।
  - `read_email(index)` — ভ্যালিডেট করে (খালি চেক + সীমা চেক), ১-ভিত্তিক → ০-ভিত্তিকে রূপান্তর
    করে, তারপর নির্বাচিত ইমেইলে `display_full_email()` কল করে।
  - `delete_email(index)` — একই ভ্যালিডেশন, তারপর `del self.emails[actual_index]` (পরের
    ইমেইলগুলো এক নম্বর নিচে নেমে আসে) এবং নিশ্চিতকরণ ছাপায়।

## ৪. 🔁 ধাপে ধাপে এক্সিকিউশন ফ্লো (`main()` যা করে)

> চালনার ক্রম `main()` দ্বারা পরিচালিত, যা `if __name__ == '__main__':` গার্ডের নিচে কল হয়।

1. **`tory = User('Tory')`** — একটি `User` অবজেক্ট তৈরি হয়। এর `__init__` `name='Tory'` সেট
   করে এবং একটি ব্যক্তিগত, খালি `Inbox` তৈরি করে (`tory.inbox.emails == []`)।
2. **`ramy = User('Ramy')`** — Ramy-র ক্ষেত্রেও একই, তার নিজস্ব আলাদা খালি ইনবক্সসহ।
3. **`tory.send_email(ramy, 'Hello', 'Hi Ramy, just saying hello!')`**
   - `Email(sender=tory, receiver=ramy, subject='Hello', body=..., timestamp=now, read=False)` গড়ে।
   - `ramy.inbox.receive_email(email)` কল করে → ইমেইলটি **Ramy-র** লিস্টে যোগ হয়।
   - ছাপায়: `Email sent from Tory to Ramy!`
4. **`ramy.send_email(tory, 'Re: Hello', 'Hi Tory, hope you are fine.')`**
   - একটি উত্তর `Email` গড়ে **Tory-র** ইনবক্সে ডেলিভার করে; নিশ্চিতকরণ ছাপায়।
5. **`ramy.check_inbox()`**
   - হেডার `Ramy's Inbox:` ছাপায় এবং `ramy.inbox.list_emails()` কল করে।
   - ইনবক্স খালি নয়, তাই লুপ করে ছাপায়:
     `1. [Unread] From: Tory | Subject: Hello | Time: YYYY-MM-DD HH:MM`
     (`[Unread]` কারণ `read` তখনো `False`; এই লাইনটি `__str__` গড়ে)।
6. **`ramy.read_email(1)`**
   - ভ্যালিডেশন পেরোয় (ইনবক্স খালি নয়, ইনডেক্স ১ বৈধ)।
   - ১-ভিত্তিক `1` → ০-ভিত্তিক `0`-তে রূপান্তর করে, ইমেইলটি এনে `display_full_email()` কল করে।
   - যা পূর্ণ From/To/Subject/Received/Body ব্লক ছাপায় **এবং `read = True` সেট করে**।
7. **`ramy.delete_email(1)`**
   - ভ্যালিডেশন পেরোয়, ইনডেক্স রূপান্তর করে, `del self.emails[0]` চালায়।
   - Ramy-র লিস্ট খালি হয়ে যায়; ছাপায় `Email deleted.`
8. **`ramy.check_inbox()`**
   - আবার `list_emails()` কল করে; এখন `not self.emails` হলো `True`, তাই
     `Your inbox is empty.` ছাপিয়ে early return করে।

### এক নজরে ডেটা-ফ্লো
```
User.send_email()
   └─> Email অবজেক্ট তৈরি করে
        └─> receiver.inbox.receive_email(email)   # ইমেইল লিস্টে যোগ হয়
User.check_inbox()
   └─> Inbox.list_emails()  ──> print ট্রিগার করে Email.__str__()
User.read_email(i)
   └─> Inbox.read_email(i) ──> Email.display_full_email() ──> mark_as_read()
User.delete_email(i)
   └─> Inbox.delete_email(i) ──> del emails[i]
```

## ৫. 📝 ব্যাখ্যাসহ সোর্স কোড

> সম্পূর্ণ কমেন্টসহ কোডটি **`email_simulator_annotated.py`** ফাইলে আছে (এই README-এর সাথে
> দেওয়া হয়েছে)। এটি হুবহু মূল প্রোগ্রাম, সাথে বিস্তারিত ধাপে ধাপে বাংলা কমেন্ট এবং পেস্ট করা
> মার্কডাউন ত্রুটিগুলো বৈধ পাইথনে ফিরিয়ে আনা হয়েছে (`__init__`, `__str__`, `__name__`,
> `datetime.datetime.now()`, এবং `<` / `>`)। **কোনো লজিক পরিবর্তন করা হয়নি।**
> সুবিধার্থে সেই ব্যাখ্যাসহ সোর্স কোডের একটি কপি নিচে দেওয়া হলো।

```python
import datetime  # সময় এবং তারিখ নিয়ন্ত্রণের জন্য পাইথনের বিল্ট-ইন datetime মডিউল ইম্পোর্ট করা হলো


# ==============================================================================
# ১. Email ক্লাস (ইমেইল অবজেক্টের কাঠামো ও তথ্য সংরক্ষণ)
# ==============================================================================
class Email:
    # **init** কনস্ট্রাক্টর: নতুন একটি ইমেইল অবজেক্ট তৈরি হওয়ার সময় এটি স্বয়ংক্রিয়ভাবে রান হয়
    def __init__(self, sender, receiver, subject, body):
        self.sender = sender          # প্রেরকের User অবজেক্টটি সংরক্ষণ করে
        self.receiver = receiver      # প্রাপকের User অবজেক্টটি সংরক্ষণ করে
        self.subject = subject        # ইমেইলের বিষয়বস্তু (Subject) সংরক্ষণ করে
        self.body = body              # ইমেইলের মূল বার্তা (Body) সংরক্ষণ করে
        self.timestamp = datetime.datetime.now()  # ইমেইলটি ঠিক যে মুহূর্তে তৈরি হচ্ছে তখনকার সময় ও তারিখ রেকর্ড করে
        self.read = False             # ইমেইলটি পড়া হয়েছে কি না তার অবস্থা রাখে (ডিফল্টভাবে অপঠিত/False থাকে)

    # ইমেইলকে 'পঠিত' (Read) হিসেবে চিহ্নিত করার মেথড
    def mark_as_read(self):
        self.read = True  # self.read এর মান বদলে True করে দেয়

    # ইমেইলের সমস্ত তথ্য (প্রেরক, প্রাপক, বিষয়, সময় ও বডি) বিস্তারিত স্ক্রিনে দেখানোর মেথড
    def display_full_email(self):
        self.mark_as_read()  # ইউজার পুরো মেইলটি ওপেন করায় এটিকে 'পঠিত' হিসেবে চিহ্নিত করা হলো
        print('\n--- Email ---')
        print(f'From: {self.sender.name}')      # প্রেরকের অবজেক্ট থেকে তার নাম প্রিন্ট করে
        print(f'To: {self.receiver.name}')        # প্রাপকের অবজেক্ট থেকে তার নাম প্রিন্ট করে
        print(f'Subject: {self.subject}')        # বিষয় প্রিন্ট করে
        # strftime ব্যবহার করে তারিখ ও সময়কে 'YYYY-MM-DD HH:MM' ফরম্যাটে সুন্দর করে দেখায়
        print(f"Received: {self.timestamp.strftime('%Y-%m-%d %H:%M')}")
        print(f'Body: {self.body}')              # মূল বার্তা প্রিন্ট করে
        print('------------\n')

    # ডান্ডার/স্পেশাল মেথড **str__: যখন এই ইমেইল অবজেক্টটিকে ইনবক্সের তালিকায় ১ লাইনে প্রিন্ট করা হবে, তখন এটি রান হয়
    def __str__(self):
        # শর্টহ্যান্ড if-else: read সত্য হলে 'Read', মিথ্যা হলে 'Unread' স্ট্যাটাস সেট করে
        status = 'Read' if self.read else 'Unread'
        # এক লাইনের সংক্ষিপ্ত রূপ ফেরত দেয়
        return f"[{status}] From: {self.sender.name} | Subject: {self.subject} | Time: {self.timestamp.strftime('%Y-%m-%d %H:%M')}"


# ==============================================================================
# ২. User ক্লাস (ব্যবহারকারীর অ্যাকাউন্ট ও অ্যাকশন পরিচালনা)
# ==============================================================================
class User:
    # একজন নতুন ইউজার তৈরির কনস্ট্রাক্টর
    def __init__(self, name):
        self.name = name     # ইউজারের নাম সেট করে (যেমন: "Tory" বা "Ramy")
        self.inbox = Inbox() # প্রতিটি ইউজারের জন্য একটি নিজস্ব Inbox অবজেক্ট তৈরি করে

    # অন্য কোনো ইউজারকে ইমেইল পাঠানোর মেথড
    def send_email(self, receiver, subject, body):
        # প্রেরক হিসেবে নিজেকে (self) এবং প্রাপক হিসেবে receiver-কে দিয়ে একটি Email অবজেক্ট তৈরি করে
        email = Email(sender=self, receiver=receiver, subject=subject, body=body)
        # প্রাপকের ইনবক্সে (receiver.inbox) তৈরি করা ইমেইলটি জমা দেয়
        receiver.inbox.receive_email(email)
        # সফলভাবে পাঠানো নিশ্চিত করার বার্তা প্রিন্ট করে
        print(f'Email sent from {self.name} to {receiver.name}!\n')

    # ইউজারের ইনবক্সের তালিকা দেখার মেথড
    def check_inbox(self):
        print(f"\n{self.name}'s Inbox:") # ইউজারের নাম দিয়ে হেডার প্রিন্ট করে
        self.inbox.list_emails()          # ইউজারের Inbox অবজেক্টের list_emails() মেথডটি রান করে

    # নির্দিষ্ট নম্বরের ইমেইলটি পড়ার মেথড
    def read_email(self, index):
        self.inbox.read_email(index) # Inbox ক্লাসের read_email-এ ইনডেক্সটি পাঠিয়ে দেয়

    # নির্দিষ্ট নম্বরের ইমেইলটি মুছে ফেলার মেথড
    def delete_email(self, index):
        self.inbox.delete_email(index) # Inbox ক্লাসের delete_email-এ ইনডেক্সটি পাঠিয়ে দেয়


# ==============================================================================
# ৩. Inbox ক্লাস (ইনবক্সে জমা থাকা ইমেইল ম্যানেজমেন্ট ও ভ্যালিডেশন)
# ==============================================================================
class Inbox:
    # নতুন ইনবক্স চালুর কনস্ট্রাক্টর
    def __init__(self):
        self.emails = [] # আগত সমস্ত Email অবজেক্ট জমা রাখার জন্য একটি খালি পাইথন লিস্ট তৈরি করে

    # নতুন কোনো ইমেইল আসলে সেটি লিস্টে যুক্ত (append) করার মেথড
    def receive_email(self, email):
        self.emails.append(email)

    # ইনবক্সে থাকা সব ইমেইল ১, ২, ৩ নম্বর দিয়ে তালিকায় দেখানোর মেথড
    def list_emails(self):
        # ইনবক্স যদি খালি থাকে (লিস্টে কিছু না থাকলে)
        if not self.emails:
            print('Your inbox is empty.\n')
            return # মেথড থেকে বের হয়ে যায়
        print('\nYour Emails:')
        # enumerate দিয়ে ১ থেকে কাউন্ট শুরু করে (start=1) লিস্টের প্রতিটি ইমেইল প্রিন্ট করে
        # ইমেইলটি প্রিন্ট হওয়ার সময় Email ক্লাসের **str** মেথডটি কল হয়
        for i, email in enumerate(self.emails, start=1):
            print(f'{i}. {email}')

    # ইউজার প্রদত্ত নম্বর অনুযায়ী ইমেইল পড়ার মেথড
    def read_email(self, index):
        # ইনবক্সে কোনো ইমেইল না থাকলে
        if not self.emails:
            print('Inbox is empty.\n')
            return
        # ইউজার ১-ভিত্তিক নম্বর দেয় (১, ২, ৩), কিন্তু পাইথন লিস্ট ০-ভিত্তিক (0, 1, 2)। তাই ১ বিয়োগ করা হলো
        actual_index = index - 1
        # ইনডেক্স যদি ঋণাত্মক হয় অথবা লিস্টের মোট সাইজের সমান বা বেশি হয় (ভুল নম্বর দিলে)
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
        # সঠিক নম্বর হলে ঐ নির্দিষ্ট ইমেইল অবজেক্টটির display_full_email() মেথডটি কল করা হয়
        self.emails[actual_index].display_full_email()

    # ইউজার প্রদত্ত নম্বর অনুযায়ী ইমেইল ডিলিট করার মেথড
    def delete_email(self, index):
        # ইনবক্স খালি কি না তা চেক করা
        if not self.emails:
            print('Inbox is empty.\n')
            return
        # ০-ভিত্তিক ইনডেক্সে রূপান্তর
        actual_index = index - 1
        # ইনডেক্স সীমার বাইরে কি না চেক করা
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
        # del কিওয়ার্ড ব্যবহার করে লিস্ট থেকে নির্দিষ্ট ইমেইল অবজেক্টটি ডিলিট করে দেওয়া
        del self.emails[actual_index]
        print('Email deleted.\n')


# ==============================================================================
# ৪. main() ফাংশন (সম্পূর্ণ সিস্টেমটি পরীক্ষা/সিমুলেট করার প্রধান ড্রাইভার)
# ==============================================================================
def main():
    # step 1: Tory এবং Ramy নামে ২টি User অবজেক্ট তৈরি করা হলো
    tory = User('Tory')
    ramy = User('Ramy')
    # step 2: Tory থেকে Ramy-কে ইমেইল পাঠানো হলো
    tory.send_email(ramy, 'Hello', 'Hi Ramy, just saying hello!')
    # step 3: Ramy থেকে Tory-কে ইমেইল পাঠানো হলো
    ramy.send_email(tory, 'Re: Hello', 'Hi Tory, hope you are fine.')
    # step 4: Ramy তার ইনবক্সের তালিকা চেক করল (এখানে Tory-র পাঠানো অপঠিত মেইলটি দেখাবে)
    ramy.check_inbox()
    # step 5: Ramy তার ১ নম্বর ইমেইলটি ফুল ওপেন করে পড়ল (যার ফলে মেইলটি 'Read' হয়ে যাবে)
    ramy.read_email(1)
    # step 6: Ramy ১ নম্বর ইমেইলটি তার ইনবক্স থেকে মুছে ফেলল
    ramy.delete_email(1)
    # step 7: Ramy আবার ইনবক্স চেক করল (ইনবক্স ফাঁকা হয়ে গেছে দেখতে পাবে)
    ramy.check_inbox()


# প্রোগ্রামটি সরাসরি রান করা হলে main() ফাংশনটি চালু হবে
if __name__ == '__main__':
    main()
```

## ৭. 🧠 মূল শিক্ষণীয় বিষয়

- **স্ট্রিংয়ের বদলে অবজেক্ট:** `sender`/`receiver`-কে `User` অবজেক্ট হিসেবে রাখায় পরিষ্কার
  ডট-অ্যাক্সেস (`self.sender.name`) ও ভবিষ্যতের সম্প্রসারণযোগ্যতা পাওয়া যায়।
- **Composition:** `User`-এর একটি `Inbox` *আছে*; `Inbox`-এর অনেকগুলো `Email` *আছে* —
  ইনহেরিটেন্স ছাড়াই একটি বাস্তবসম্মত "has-a" মডেল।
- **ম্যাজিক মেথড:** `__init__` বৈধ শুরুর অবস্থা নিশ্চিত করে; `__str__` কল-সাইটে কোনো অতিরিক্ত
  পরিশ্রম ছাড়াই অবজেক্টকে সুন্দরভাবে ছাপতে দেয়।
- **ভ্যালিডেশন:** গার্ড ক্লজ (খালি চেক + সীমা চেক + ১-ভিত্তিক→০-ভিত্তিক রূপান্তর) সম্ভাব্য
  ক্র্যাশকে বন্ধুত্বপূর্ণ বার্তায় রূপান্তর করে।
- **Separation of concerns:** `User` সংরক্ষণ/ভ্যালিডেশনের দায়িত্ব `Inbox`-কে দেয়, ফলে প্রতিটি
  ক্লাস ছোট, কেন্দ্রীভূত এবং স্বাধীনভাবে পরিবর্তনযোগ্য থাকে।
